앱스 스크립트가 뭔가요?

구글 시트 안에 들어 있는 작은 자동화 기능이에요. 따로 설치할 것도, 서버를 빌릴 것도 없어요. 시트에 코드를 붙여넣으면 시트가 메일을 보내고, 정해진 시간에 혼자 움직이고, 입력 화면이 있는 웹 주소까지 만들어 줘요. 구글 계정만 있으면 무료로 쓸 수 있어요.

처음 한 번, 이 순서대로

  1. 구글 시트를 새로 만들어요연습용으로 빈 시트를 하나 만드세요. 중요한 자료가 든 시트로 연습하지 마세요.
  2. 확장 프로그램 → Apps Script시트 위쪽 메뉴에서 눌러요. 새 탭에 코드 편집기가 열려요.
  3. 기존 내용을 지우고 코드를 붙여넣어요AI가 준 Code.gs 내용을 그대로 붙여넣어요. 화면이 있는 앱이라면 파일 추가(+) → HTML로 index.html도 만들어요.
  4. 저장하고 실행해요디스크 모양 저장 버튼을 누른 뒤, 위쪽 함수 목록에서 실행할 함수를 고르고 '실행'을 눌러요.
  5. 권한을 승인해요처음 실행하면 권한을 묻는 창이 떠요. 계정 선택 → '고급' → '(프로젝트 이름)(으)로 이동' → 허용 순서로 눌러요.
  6. 웹 주소로 배포해요 (입력 화면이 있을 때만)오른쪽 위 '배포' → '새 배포' → 유형에서 '웹 앱' 선택 → 액세스 권한을 정하고 배포하면 주소가 나와요.
  7. 자동 실행을 걸어요 (필요할 때만)왼쪽 시계 모양 '트리거' → 트리거 추가 → 실행할 함수와 시간을 고르면 매일 알아서 움직여요.
⚠️ '안전하지 않은 페이지'라고 뜨면요내가 직접 만든 스크립트라 구글이 아직 검토하지 않았다는 뜻이에요. 남이 보낸 코드가 아니라 내가 붙여넣은 코드일 때만 '고급 → 이동'으로 진행하세요.
🔑 API 키는 코드에 쓰지 마세요Gemini 같은 키는 프로젝트 설정(톱니바퀴) → 스크립트 속성에 저장하고, 코드에서는 불러다 쓰게 해달라고 AI에게 말하세요. 시트 셀이나 채팅창에 키를 붙여넣지 않는 것도 중요해요.

자주 막히는 곳

실행했는데 아무 일도 안 일어나요
함수 목록에서 엉뚱한 함수를 고른 경우가 많아요. AI에게 "어떤 함수를 실행해야 하나요?"라고 물어보세요.
빨간 글씨가 떴어요
'고치기 프롬프트'의 오류가 났을 때를 복사해서, 빨간 글씨를 그대로 붙여넣으면 돼요.
웹 주소를 열면 화면이 하얘요
index.html 파일 이름이 다르거나 배포를 안 한 경우예요. 배포 → 새 배포를 다시 해보세요.
코드를 고쳤는데 그대로예요
배포한 앱은 '배포 관리 → 수정 → 새 버전'으로 다시 배포해야 반영돼요.
